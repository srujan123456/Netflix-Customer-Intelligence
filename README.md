# Netflix Customer Intelligence & AI Analytics Copilot

## Project Overview
The Netflix Customer Intelligence & AI Analytics Copilot is a data-driven platform designed to analyze customer behavior, predict churn, segment customers, estimate Customer Lifetime Value (CLV), and generate business insights using machine learning and Generative AI.

## Key Features
- **Executive Dashboard:** Overview of customer metrics and business performance.
- **Customer Analytics:** Analyze customer demographics, engagement, and subscription behavior.
- **Churn Prediction:** Predict customer churn risk using machine learning.
- **Customer Segmentation:** Group customers based on behavioral patterns.
- **CLV Prediction:** Estimate Customer Lifetime Value.
- **AI Analytics Copilot:** Ask business questions using natural language and generate SQL-based insights.
- **Support Intelligence:** Analyze customer support tickets and feedback.
- **Automated Reports:** Generate business reports.

## Technologies Used
- Python
- SQL
- PostgreSQL
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Generative AI
- Retrieval-Augmented Generation (RAG)

## Application
The project uses a Streamlit application to present customer analytics, machine learning predictions, and AI-powered business insights.
